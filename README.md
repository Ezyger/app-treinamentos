# 🏋️ Academia App

Aplicativo mobile desenvolvido para ajudar usuários a **organizar e acompanhar seus treinos de academia**.

O projeto está sendo desenvolvido com **Angular, Ionic e Capacitor**, com foco em uma experiência simples para dispositivos móveis e na aplicação de boas práticas de desenvolvimento.

> 🚧 Projeto em desenvolvimento.

---

## 🚀 Tecnologias

- Angular
- Ionic 8
- TypeScript
- Capacitor
- RxJS

### Ambiente de desenvolvimento

- Node.js 20+
- Angular CLI
- Ionic CLI

---

## 📱 Sobre o projeto

A proposta do **Academia App** é permitir que o usuário organize seus treinos e acompanhe sua rotina de exercícios através de uma aplicação mobile.

Além de sua finalidade prática, o projeto também é utilizado para estudo e aplicação de conceitos relacionados ao desenvolvimento de aplicações modernas com **Angular e Ionic**.

---

## 🏗️ Desenvolvimento

O projeto utiliza **Angular** como framework principal e **Ionic** para construção da interface mobile.

O **Capacitor** é utilizado como camada de integração entre a aplicação web e as plataformas nativas.

A aplicação é desenvolvida utilizando **TypeScript** e os recursos do ecossistema Angular.

---

## 🧪 Qualidade de código

O projeto possui estrutura preparada para:

- Execução de testes com Karma
- ESLint

À medida que o projeto evoluir, novos testes serão adicionados para as principais regras e funcionalidades da aplicação.

## ▶️ Executando o projeto

### Pré-requisitos

Tenha instalado:

- Node.js 20+
- Ionic CLI

### Clone o repositório

```bash
git clone https://github.com/Ezyger/app-treinamentos.git
cd app-treinamentos
```

### Instale as dependências

```bash
npm install
```

### Execute no navegador

```bash
ionic serve
```
